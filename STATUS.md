# Project status

## Project type

A curated, machine-readable resource catalogue for AI production readiness.

## Current public state

Maintained. Catalogue data, link-check records, releases, and the validation workflow are the source of truth for the public catalogue.

## Intended use

Use it to find source material for evaluation, governance, security, observability, and deployment work.

## Not a replacement for

It is not a compliance certification, security assessment, vendor endorsement, or guarantee that a linked resource fits a particular system.

## Feedback and maintenance

Propose additions, corrections, or dead-link reports through GitHub Issue. Follow the repository's inclusion and evidence rules.

## Public boundary

The catalogue records public resources and curation metadata only; it does not collect private operating data or customer material.
